# BioUrban — מנוע האינטליגנציה הביו-עירונית

ספרייה של פתרונות ביומימטיים לאתגרי תכנון עירוני: לכל אתגר מוצגים פתרונות בהשראת
בעלי חיים, צמחים ודומם, עם מנגנון ביולוגי, יישום אדריכלי ומדדי השפעה.

**האפליקציה החיה:** https://anat1969.github.io/---GH/

---

## מאגר הנתונים נמצא ב-GitHub

אין שרת ואין בסיס נתונים. כל התוכן יושב בשני קבצי JSON בתוך הריפו:

| קובץ | תוכן |
| --- | --- |
| [`data/challenges.json`](data/challenges.json) | האתגרים העירוניים |
| [`data/solutions.json`](data/solutions.json) | הפתרונות, כל אחד משויך לאתגר |

עריכה של אחד הקבצים ודחיפה ל-`main` היא הדרך לפרסם תוכן חדש: GitHub Actions
מריץ בדיקת תקינות, בונה מחדש ומעלה לאוויר. אין מיגרציות, אין מפתחות API, ואין
מה להגדיר מחוץ לריפו.

מבנה הרשומות והכללים מתועדים ב-[`data/README.md`](data/README.md).

### גם התמונות

לכל פתרון שתי תמונות — המנגנון הביולוגי והיישום האדריכלי — והן נשמרות כקבצים
ב-`public/solutions/` בתוך הריפו. הן מיוצרות פעם אחת עם `npm run generate:images`
ומאותו רגע מוגשות מהאתר כמו כל קובץ אחר. האתר החי לא קורא לשום שירות תמונות.

### מה עם המידע של המשתמש?

הפתרונות שנשמרים ב"סביבת העבודה" והתמונות שמעלים לכרטיסים נשמרים ב-`localStorage`
של הדפדפן — הם לא עוזבים את המחשב. מסביבת העבודה אפשר לייצא JSON או Markdown,
ולייבא את ה-JSON בחזרה בדפדפן אחר.

## הרצה מקומית

```bash
npm install
npm run dev
```

הפקודות הזמינות:

| פקודה | מה היא עושה |
| --- | --- |
| `npm run dev` | שרת פיתוח על http://127.0.0.1:8080 |
| `npm run build` | בנייה לתיקיית `dist/` |
| `npm run preview` | תצוגה מקדימה של הבנייה |
| `npm run typecheck` | בדיקת טיפוסים |
| `npm run lint` | ESLint |
| `npm run validate:data` | בדיקת תקינות של `data/` |
| `npm run generate:images` | ייצור התמונות לכרטיסים (דורש `FAL_KEY`) |

## פריסה

`.github/workflows/deploy.yml` רץ על כל דחיפה ל-`main`:

1. `validate:data` — מוודא שאין מזהים כפולים, קטגוריות לא חוקיות, פתרונות
   שמצביעים על אתגר שלא קיים או מדדים מחוץ לסולם.
2. `typecheck` ואז `build`.
3. העלאה ל-GitHub Pages, כולל `404.html` שמאפשר קישורים עמוקים לעבוד.

הפעלה חד-פעמית: **Settings → Pages → Source → GitHub Actions**.

## ארכיטקטורה

```
data/            מאגר הנתונים (JSON, מנוהל בגיט)
scripts/         בדיקת תקינות הנתונים וייצור התמונות
src/data/        טעינה, טיפוסים ואינדקסים נגזרים
src/lib/         חיפוש, פרשנות אדריכלית, פרומפטים לתמונות, אחסון מקומי
src/components/  רכיבי ממשק
src/pages/       מסכים
```

מחסנית: React 18, TypeScript, Vite, Tailwind CSS, React Router, Recharts.
